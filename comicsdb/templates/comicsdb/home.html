{% endblock %} {% block content %} {# What is Metron #}

{% trans "What is Metron?" %}

{% trans "A community-built, open database for comic book metadata — free from corporate control." %}

{% blocktrans %}Metron is a community-based site whose goal is to build an open database with a REST API for comic books.{% endblocktrans %}

{% blocktrans %}Originally, when this project was created, the only comic book database that provided a REST API for users was Comic Vine. Unfortunately, it's a corporately-owned service and the community that uses it has no control over the resources provided to maintain it or ensure its continued accessibility. This project was started to create an alternative.{% endblocktrans %}

{% blocktrans %}Note: Recently, the Grand Comics Database created an API, which you may wish to explore as an alternative.{% endblocktrans %}
